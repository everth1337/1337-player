# 1337 Player (ранее Nexi)

Основа — [Myspoti](https://github.com/kota-zo/myspoti), GPL-3.0. Все исходные уведомления об авторстве и лицензиях сохранены. Изменения Nexi также распространяются по GPL-3.0. Полные изменённые исходники передаются пользователю вместе с APK.

Снимок исходников ветки main получен 8 ноября 2026 года. SHA-256 исходного архива до изменений: `d3a0cec290c50237d21a2b26c5f99da21d03506a55069965980a3efdcb9f2dc3`.

## Изменения

- Имя, значок и сиреневая тема Nexi.
- Мобильное оформление Immersive по умолчанию.
- Canvas-видео выключены по умолчанию для новых настроек.
- Аудиофайлы из приватной папки Nexi 0.2–0.4 переносятся в отдельную приватную папку и доступны в разделе локальных файлов. Служебные файлы нового движка туда не попадают. Коллизия имён сохраняет обе копии.
- Дополнительный источник Nexi Audius для записей, открытых автором для скачивания.

Каталог, поиск, плейлисты, экраны плеера и меню рисуются нативно. Воспроизведение Spotify использует скрытый официальный веб-плеер движка Myspoti. Открытые страницы каталога и медиатека кэшируются, но кэш каталога не содержит музыку. Прослушивание Spotify без сохранённого аудио требует сети.

## Сборка

Нужны JDK 17 или новее, Android SDK Platform 37.0 и Build-Tools 36.0.0. В папке base создай local.properties с sdk.dir.

Выполни в папке base.

    .\gradlew.bat :app:assembleRelease '-PnexiBuild' '-Pabis=arm64-v8a' '-PappVersionName=2.4.5' '-PappVersionCode=505'

Настройки ключа описаны в base/app/build.gradle.kts. Ключ подписи в исходники не включён.

Из корня можно вызвать `./build-nexi.ps1` для Debug или `./build-nexi.ps1 -Configuration Release` со своим ключом в переменных окружения. Для Java 25 под Windows при ошибке loopback connection помогает короткий существующий каталог сокетов в `JAVA_TOOL_OPTIONS=-Djdk.net.unixdomain.tmpdir=C:\\nexi-sockets`.

Проверки изменений находятся в `NexiNativeSmokeTest.kt`, проверки сопоставления Audius запускаются через `node nexi-audius/test.cjs`. В androidTest используются вымышленные данные каталога и генерируемый WAV. Они не включаются в основной APK.

Nexi Audius устанавливается как ZIP через «Настройки → Расширения → Установить из файла». Расширение ищет совпадение по названию, исполнителю и длительности. Оно предлагает MP3-поток только для записи, у которой Audius явно разрешает скачивание без дополнительных условий.

## Подборка расширений в 2.4.1

В оба варианта экрана расширений добавлена сворачиваемая карточка «Для офлайна и J-pop». В APK включены неизменённые официальные ZIP-релизы:

- YouTube Music Download Helper 1.0.4, y-exe: https://github.com/y-exe/myspoti-youtube-music/tree/v1.0.4
- Lyrics Romanizer 0.4.0, Illumye: https://github.com/Illumye/myspoti-romanizer/tree/v0.4.0

Оба GPL-3.0. Лицензии находятся внутри пакетов; полные архивы соответствующих исходников включены в third-party/. Установка использует обычную проверку пакета, показ разрешений и разрешение конфликтов источников. Автоматического предоставления прав нет. Наличие пакетов в APK позволяет устанавливать их без сети. Для поиска и загрузки музыки сеть нужна.

YouTube Music Helper сохраняет AAC/M4A и не требует токена Eclipse. Сопоставление строгое: отсутствие совпадения не считается успешной загрузкой. Этот источник не извлекает аудио Spotify. Романизация работает локально с уже полученными текстами, не переводит их и может ошибаться в чтении иероглифов.
## Стабильность в 2.4.2

После OutOfMemoryError на телефоне с большой очередью и несколькими включёнными источниками ограничена фоновая обработка: один загружаемый трек и один AAC-кодировщик одновременно. Очередь остаётся сохраняемой между запусками. Это снижает пиковую нагрузку расширений, которые могут самостоятельно создавать несколько JavaScript-контекстов для одного поиска; полного устранения любой нехватки памяти не гарантирует.

## 2.4.5

- Отдельный foreground-сервис типа dataSync поддерживает очередь загрузок независимо от воспроизведения. Уведомление показывает оставшееся количество и позволяет отменить очередь. Частичный wake lock ограничен шестью часами и освобождается при остановке сервиса.
- При системном лимите фонового сервиса работа приостанавливается с сохранением очереди. Открытие приложения продолжает её. Если процесс убит, сохранённая очередь восстанавливается при следующем запуске. Принудительная остановка приложения не обходится.
- Без сети обработка ждёт подключения. Если соединение исчезло во время неудачной загрузки, запрос возвращается в очередь. Файлы, успешно скачанные ранее, сохраняются.
- Состояния «Ожидает в очереди» и «Скачивание» разделены. Поиск на Immersive-экране загрузок фильтрует также ожидающие треки.
- YouTube Music Helper 1.0.4-nexi.2 (код 13) возвращает структурированное состояние rate-limited с паузой 60 секунд, вместо ошибки скрипта и отключения после трёх ошибок. Приложение учитывает cooldown источника и сохраняет запрос для повторной попытки. Лимиты не снимаются.
- DownloadServiceTest на эмуляторе проверяет сохранение очереди при системной остановке, продолжение при открытии, отмену и освобождение ресурсов. Регрессии расширения находятся в nexi-youtube/.

Автосинхронизация отмеченных коллекций работает при открытии/работе приложения и доступной сети; чтение обновлений коллекций ждёт Wi-Fi. Это не постоянно действующая задача при закрытом или принудительно остановленном приложении. Наличие трека в Spotify не гарантирует совпадение и доступность аудио у расширения.
