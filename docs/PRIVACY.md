# Приватность публичной сборки

Репозиторий содержит код, зависимости/лицензии, тестовые данные и встроенные пакеты расширений. В него не включаются данные личного устройства разработчика: учётные записи, Spotify-cookie/токены, история, частные плейлисты, скачанная музыка, скриншоты, диагностические дампы, локальные пути SDK и ключи подписи.

При первом запуске каждый пользователь входит в собственный аккаунт. Данные входа и загрузки создаются приложением на его устройстве; готовых чужих сессий в APK нет.

## Сетевые обращения

- Spotify используется для аккаунта, каталога и онлайн-воспроизведения через движок Myspoti.
- Источники музыки, текстов, обложек и другие расширения обращаются к своим сервисам в соответствии с выданными разрешениями. Читай запрос прав при установке расширения.
- YouTube Music Helper использует указанные в манифесте хосты YouTube/Googlevideo. Lyrics Romanizer работает локально с предоставленным ему текстом и не запрашивает сеть.
- GitHub используется для обновлений приложения и каталога расширений. Для проверки версии не требуется вход пользователя в GitHub.
- Собственный сервер сбора данных в форке не добавлен. Это не заявление об отсутствии сетевых запросов или аналитики у внешних сервисов.

Last.fm и другие необязательные интеграции настраиваются пользователем отдельно. Публичная сборка не содержит личных подключений автора.

## Диагностика

Перед отправкой issue или лога удали cookie, bearer-токены, адреса с временной подписью, email и личные названия плейлистов. Не публикуй полный `adb logcat` устройства. Расширения могут показывать диагностические сведения о запросах — проверь их перед отправкой.
