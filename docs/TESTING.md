# Проверки и известные границы

Проверки форка сосредоточены на изменённых участках. Это не полный аудит всех компонентов Myspoti и внешних сервисов.

- `OfflineDownloaderTest`: выбор/проверка файлов загрузки, 10 unit-проверок.
- `UpdateCheckerTest`: сравнение версий и выбор APK; в 2.4.6 добавлена проверка имени 1337 Player, архитектуры, канала и приоритета над именем upstream.
- `DownloadServiceTest`: на эмуляторе API 35 проверены системная остановка, сохранение очереди, продолжение при открытии, отмена, освобождение wake lock и уведомления. Использует вымышленные запросы, не личный аккаунт.
- `nexi-youtube/nexi-status.scenario.json`: статусы HTTP 200/302/307/403/500.
- `nexi-youtube/nexi-rate-limit.scenario.json`: три последовательных HTTP 429 дают структурированную паузу, а не ошибку скрипта.
- `node nexi-youtube/scripts/nexi-rate-limit-test.cjs`: шесть сценариев локального лимита в английской и японской локалях, без сетевых запросов.
- На Android 16 проверялось воспроизведение завершённого M4A при отключённых Wi-Fi и мобильных данных. Короткая проверка фона подтвердила активный сервис при свёрнутом приложении.

Наблюдалась выгрузка процесса Android из-за нехватки памяти. Фоновый сервис и ограничение параллелизма уменьшают риск остановки очереди, но не гарантируют непрерывную многосуточную работу. После выгрузки/принудительной остановки открой приложение для продолжения.

Совпадение аудио у источника не гарантируется для каждой песни. Разные версии, каверы и отсутствие записи могут приводить к отказу сопоставления. Проверки соответствия не ослаблялись ради количества скачанных файлов.

Личные логи устройства и данные музыкального аккаунта намеренно не публикуются.
