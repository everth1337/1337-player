## Расширения

- YouTube Music Download Helper: [y-exe, v1.0.4](https://github.com/y-exe/myspoti-youtube-music/tree/v1.0.4). Исходный архив — `third-party/youtube-source.zip`; изменённый полный исходник `1.0.4-nexi.2` — `nexi-youtube/`. Исправлены проверка перенаправления и возврат cooldown при ограничении запросов. Это локальная версия форка, не официальный upstream-релиз.
- Lyrics Romanizer: [Illumye, v0.4.0](https://github.com/Illumye/myspoti-romanizer/tree/v0.4.0). Неизменённый пакет включён в APK; полный исходный архив — `third-party/romanizer-source.zip`.
- Готовые ZIP расширений находятся в `base/app/src/main/assets/nexi-extensions/`. Они нужны для установки без скачивания самого пакета; доступ к музыкальному источнику всё равно требует сети.
- Nexi Audius: отдельный исходник `nexi-audius/`, предназначенный для записей, открытых автором для скачивания.

Остальные унаследованные компоненты, проекты и лицензии перечислены в [THIRD_PARTY_NOTICES](../THIRD_PARTY_NOTICES.md). Точные версии библиотек — в Gradle catalog. Исходный README и журнал Myspoti сохранены в `docs/upstream/`.

Ключи подписи, аккаунты пользователей и музыкальные файлы не являются частью исходного дистрибутива. Каждый публичный APK сопровождается полным архивом исходников соответствующего Git-коммита.
