# Участие в разработке

1. Прочитай [инструкцию сборки](docs/BUILDING.md) и [лицензию](LICENSE).
2. Создай ветку с небольшим законченным изменением. Сохраняй заголовки авторства и лицензии унаследованных файлов.
3. Опиши проблему, изменение поведения и выполненные проверки в pull request.
4. Для исправления ошибки добавляй проверку поведения, когда она действительно помогает поймать регрессию.

В issue укажи версию приложения, версию Android, источник загрузок и шаги воспроизведения. Не прикладывай токены, cookie, Spotify-профиль, приватные плейлисты, адреса с подписью, полные логи телефона или ключ подписи APK. Сначала удали личные данные из диагностики.

Изменения распространяются на условиях GPL-3.0. Это форк Myspoti; не выдавай унаследованные компоненты за полностью новую реализацию. Релизы и секреты подписания управляются сопровождающим; PR-проверки доступа к ним не имеют.
