# Изменения 1337 Player

## 2.4.6

- Первый публичный релиз 1337 Player: полные исходники, GPL-3.0, сведения об основе и изменениях, инструкции для пользователей и разработчиков.
- Проверка обновлений направлена на `everth1337/1337-player`. Добавлен выбор APK с именем 1337 Player по архитектуре и каналу.
- GitHub Actions для проверок и выпуска подписанного ARM64 APK, соответствующих исходников и SHA-256.
- В лицензиях приложения указана публичная страница исходников.
- Для перехода с 2.4.5 установите этот APK вручную поверх приложения. Следующие релизы будут доступны через проверку обновлений.
- Сохраняются исправления очереди и расширения из 2.4.5. Личные данные и музыка не включены.

## 2.4.5

- Фоновый сервис загрузок с уведомлением и остановкой очереди.
- Системный timeout сохраняет очередь; открытие приложения продолжает работу.
- Ожидание сети и сохранение запроса при обрыве подключения.
- Раздельные состояния ожидания/скачивания и поиск по ожидающим трекам.
- YouTube Music Helper `1.0.4-nexi.2`: ограничение запросов возвращает cooldown вместо ошибки скрипта и отключения после трёх ошибок. Очередь ждёт установленную паузу.

## 2.4.4

- Переименование Nexi в 1337 Player без смены идентификатора Android.
- Удаление донатных пунктов и автоматических просьб о поддержке; авторство и GPL оставлены в лицензиях.
- Исправление подписи скачанного: формат/качество определяет источник, не каждый файл является lossless FLAC.

## 2.4.3

- YouTube Music Helper `1.0.4-nexi.1`: перенаправление страницы проверки не отключает источник; доступность проверяется при реальной попытке.

## 2.4.2

- Один рабочий поток загрузки и один AAC-кодировщик для уменьшения пикового расхода памяти. Выгрузка Android при нехватке памяти всё ещё возможна.

## 2.4.1

- Карточка «Для офлайна и J-pop» с YouTube Music Download Helper и Lyrics Romanizer.
- Локальные ZIP-пакеты устанавливаются с обычной проверкой прав. Добавлен переключатель романизации.

## 2.4.0

- Переход раннего Nexi на нативную основу Myspoti, сиреневая тема и Immersive по умолчанию.
- Миграция старого локального аудио Nexi без перезаписи при конфликте имён.
- Дополнительный источник Nexi Audius для разрешённых автором загрузок.

История оригинальной основы: [Myspoti CHANGELOG](docs/upstream/CHANGELOG.md). Версии до 2.4.6 были локальными сборками и не являются отдельными публичными релизами этого репозитория.
